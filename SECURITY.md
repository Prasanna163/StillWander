# Security policy

## Supported version

Security fixes are currently provided for Still Wander 1.0.x on Minecraft 1.21.11.

## Reporting a vulnerability

Use the repository's **Security → Report a vulnerability** flow so details are not disclosed publicly. Include reproduction steps, affected versions, and the expected impact. Do not open a public issue for an unpatched vulnerability.

Still Wander is client-side and is not intended to transmit telemetry or gameplay data to external services. Unexpected network or filesystem behavior should be reported as a security issue.
