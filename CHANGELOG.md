# Changelog

## Still Wander 1.0.0 - Minecraft 1.21.11

- Established the public Still Wander name, icon, tagline, and `stillwander` Fabric mod ID.
- Preserved the proven Cinecraft 1.1.1 cinematic camera behavior.
- Kept automatic AFK activation and added immediate toggle control on `B`.
- Included manual next-shot control on `N`.
- Included environment-aware player, entity, cave, interior, passage, forest, and landscape shots.
- Included smooth panning, entity tracking, randomized compositions, and independent cinematic FOV.
- Included full-rate cinematic rendering compatibility for Minecraft's inactivity limiter and Dynamic FPS integrations.
- Kept damage-based cinematic exit as a configurable option.
- Removed music/beat synchronization and later experimental feature layers from the public 1.0 release.
