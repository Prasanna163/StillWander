# Still Wander

Still Wander is a client-side Fabric mod that turns idle Minecraft moments into smooth cinematic camera shots of the player and the surrounding world.

## Download

| Minecraft | Mod version | Download |
| --- | --- | --- |
| 1.21.11 | 1.0.0 | [stillwander-1.0.0+1.21.11.jar](versions/stillwander-1.0.0+1.21.11.jar) |

## Install

1. Install Fabric Loader 0.19.3 or newer for Minecraft 1.21.11.
2. Install Fabric API.
3. Place the Still Wander JAR in your Minecraft `mods` folder.
4. Start Minecraft and enter a world.

Still Wander starts automatically after you remain idle. Press `B` to start or stop it immediately, and press `N` to cut to the next shot. Normal player input exits the cinematic camera.

Requires Java 21. The mod is client-side and does not need to be installed on a server.
