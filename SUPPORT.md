# Support

## Before opening an issue

Confirm all of the following:

- Minecraft is exactly 1.21.11.
- The instance uses Fabric Loader 0.19.3 or newer.
- Fabric API is installed.
- Only one Still Wander/Cinecraft/IdleLens JAR is present.
- Java 21 or newer is being used.

If the game crashes, attach the newest file from `crash-reports` and the relevant `logs/latest.log`. Remove usernames, access tokens, server addresses, and other private information first.

For camera-behavior reports, include the environment, nearby entities, whether the player was above ground or in a cave/interior, and the control used to start or stop the cinematic.

## Compatibility reports

List the exact versions of Sodium, Iris, Dynamic FPS, Replay Mod, shader packs, and other camera/rendering mods. Test once without the suspected conflicting mod when practical.

Security-sensitive reports should use GitHub's private vulnerability reporting rather than a public issue.
